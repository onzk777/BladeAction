# 개발 일지 - 2024년 9월 10일

## 작업 개요
검술 선택 UI 시스템 정식 구현 및 전투 시스템 개선

## 주요 작업 내용

### 1. 검술 선택 UI 시스템 정식 구현
- **정식 검술 선택 루틴 구현**: 기존 테스트 모드와 분리하여 정식 모드 구현
- **UI 컴포넌트 구현**:
  - `PlayerActionSelectUI`: 플레이어 검술 선택 UI (왼쪽)
  - `EnemyActionSelectUI`: 적 검술 선택 UI (오른쪽)
  - `ActionButton`: 개별 검술 버튼 컴포넌트
- **동적 UI 생성**: 현재 장착한 유파의 검술 개수에 따라 버튼 자동 생성 (최대 5개)

### 2. 입력 시스템 통합
- **키보드 입력 지원**: W/S, ↑/↓ 방향키로 검술 선택
- **마우스 클릭 지원**: 버튼 클릭으로 검술 선택
- **InputSystem 통합**: 기존 `InputSystem_Actions.inputactions`의 Combat 액션맵에 ActionSelect 추가
- **AI 입력 차단**: 적 검술 선택은 플레이어 입력에 반응하지 않음

### 3. 전투 시작 개선
- **초기 포커싱**: 전투 시작 시 첫 번째 검술에 자동 포커싱
- **대기 시간 설정**: `GlobalConfig.BattleStartDelay` 추가 (기본 2초)
- **검술 선택 시간 보장**: 첫 공격 턴 전까지 충분한 선택 시간 제공

### 4. 버튼 외형 커스터마이징 시스템
- **Inspector 설정**: 색상, 스프라이트, 크기, 효과를 Inspector에서 설정 가능
- **상태별 스타일**: Normal/Selected 상태에 따른 시각적 구분
- **동적 스타일 적용**: 버튼 생성 시 자동으로 설정된 스타일 적용

### 5. 코드 정리 및 최적화
- **interactable 관련 코드 제거**: 불필요한 상호작용 제어 코드 정리
- **색상 처리 단순화**: Unity Button의 자동 색상 제어에 간섭하지 않도록 수정
- **테스트 모드 지원**: 테스트 모드에서도 정상 작동하도록 구현

## 기술적 개선사항

### 아키텍처 개선
- **이벤트 기반 통신**: `SwordArtSelectionManager`를 통한 이벤트 기반 UI 업데이트
- **싱글톤 패턴**: 검술 선택 관리자로 중앙 집중식 관리
- **컴포넌트 분리**: UI 로직과 비즈니스 로직의 명확한 분리

### 사용자 경험 개선
- **직관적인 입력**: 키보드와 마우스 모두 지원
- **시각적 피드백**: 선택된 검술의 명확한 하이라이트
- **자동 초기화**: 전투 시작 시 자동으로 첫 번째 검술 선택

## 해결된 문제들

### 1. 전투 재시작 버튼 문제
- **원인**: 입력 시스템 추가 후 UI 입력과 충돌
- **해결**: PlayerInput 컴포넌트 의존성 제거 및 직접 액션 참조

### 2. 버튼 텍스트 색상 문제
- **원인**: Unity Button의 자동 색상 제어와 충돌
- **해결**: interactable 관련 코드 제거 및 Inspector 설정만 사용

### 3. 초기 포커싱 문제
- **원인**: 전투 시작 시 검술이 선택되지 않은 상태
- **해결**: `SetInitialFocus()` 메서드로 첫 번째 검술 자동 선택
