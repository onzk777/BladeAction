# 발사체 기반 전투 시스템 구현 명세서

## 📋 개요

현재 타이밍 기반 전투 시스템을 발사체 기반 시스템으로 전환하여 더 직관적이고 물리적인 전투 상호작용을 구현합니다.

## 🔍 현재 시스템 분석

### 기존 방식
- 공격자와 방어자가 동일한 타이밍 윈도우를 공유
- 방어자가 공격자의 타이밍을 복제하여 판정
- `PerfectTimingWindow` 기반의 시간 기반 판정

### 문제점
- 방어자가 공격자의 타이밍에 의존적
- 실제 전투의 물리적 상호작용 부족
- 발사체가 존재하지 않아 시각적 피드백 부족

## 🎯 구현 목표

1. **발사체 기반 판정**: 공격자의 액션에 따라 실제 발사체가 생성되고 이동
2. **이중 Collider 시스템**: PerfectHitChecker와 CharacterHitBox로 정밀한 판정
3. **물리적 상호작용**: 발사체와의 실제 충돌 기반 판정
4. **독립적 턴 로직**: 각 히트가 발사체 완료 기준으로 처리

### 2. 이중 Collider 시스템

#### 각 캐릭터에 추가할 Collider

```csharp
public class CharacterHitSystem : MonoBehaviour
{
    [Header("Collider 설정")]
    [SerializeField] private Collider2D perfectHitChecker;  // 완벽 입력 가능 구간
    [SerializeField] private Collider2D characterHitBox;    // 실제 피격 판정 구간
    
    [Header("상태 관리")]
    public bool IsPerfectInputAvailable { get; private set; }
    public bool IsHitTiming { get; private set; }
    
    private void OnTriggerEnter2D(Collider2D other);
    private void OnTriggerExit2D(Collider2D other);
    public void ResetHitState();
}
```

#### Collider 구성
- **PerfectHitChecker**: 발사체가 이 구간에 진입하면 방어자에게 완벽 입력 기회 제공
- **CharacterHitBox**: 발사체가 이 구간에 진입하면 즉시 판정 발생

### 5. 판정 로직 개선

#### 새로운 판정 흐름

1. **공격자 입력** → 발사체 생성 및 발사
2. **발사체 이동** → PerfectHitChecker 트리거
3. **방어자 입력 가능** → CharacterHitBox 트리거 전까지
4. **CharacterHitBox 트리거** → 즉시 판정 발생
5. **판정 완료** → 다음 히트 또는 턴 종료

#### 턴 종료 조건
- 공격자의 마지막 히트 발사체로 인한 판정이 완료되면 턴 종료
- 기존의 턴 종료 딜레이 설정은 동일하게 적용
