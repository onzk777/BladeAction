## 📅 구현 단계

### 1단계: 1:1 일반화 (NPC vs NPC 지원) [진행도 100%] ✅

**목표:** PlayerCharacter/EnemyCharacter → Combatant1/Combatant2

**완료 현황**
- ✅ 슬롯 기반 공격/방어 입력 핸들러 정비 완료
- ✅ NPC vs NPC 전투 루프 검증 완료 (발사체 충돌, BT 기반 방어 동작)
- ✅ CombatCharacterManager 슬롯 구조 안정화 완료
- ✅ HUD/디버그 패널 실시간 스테이터스 갱신 완료 (HPPanel TeamA/TeamB 전환 완료)
- ✅ ControlType 명칭 적용 및 슬롯 제어 방식 정비 완료
- ✅ 회귀 테스트 완료 (시나리오 1, 2 정상 동작 확인)

#### 작업 항목

| 작업 | 파일 | 내용 |
|------|------|------|
| CombatCharacterManager 수정 | CombatCharacterManager.cs | PlayerCharacter/CurrentEnemy → Combatant1/2 |
| GetCharacter 로직 추가 | CombatCharacterManager.cs | Player/NPC 구분 조회 |
| AIController 생성 | Controller/AIController.cs | EnemyController 복사 → BT 기반 |
| PlayerController 수정 | Controller/PlayerController.cs | 변경 사항 없음 (이미 일반화됨) |
| CombatManager 수정 | Combat/CombatManager.cs | PlayerCharacter → Combatant1 참조 변경 |

#### 검증

```
TestScene에서:
- "Player" vs "Enemy1" → 정상 동작
- "NPC_A" vs "NPC_B" → BT vs BT 전투 동작
```

**예상 시간: 6-8시간**

**완료일**: 2025-11-23

### 2단계: Battle 클래스 분리 [진행도 100%] ✅

**목표:** 전투 로직을 Battle과 BattleExecutor로 분리

**진행 현황**
- ✅ `BattleExecutor.cs`를 별도 파일로 분리 완료
- ✅ `RunBattle()` 메서드가 `BattleExecutor`로 이동 완료
- ✅ `PerformTurn()` 메서드를 `BattleExecutor`로 이동 완료 (약 460줄)
- ✅ `EnsureAllHitJudgmentsCompleted()` 메서드를 `BattleExecutor`로 이동 완료
- ✅ `ProcessDamageCalculation()` 메서드를 `BattleExecutor`로 이동 완료
- ✅ `CombatManager.cs`에서 중복 메서드 제거 완료
- ✅ 필요한 프로퍼티들을 `internal`로 변경하여 접근 가능하도록 수정
- ✅ `BattleState` 접근성 문제 수정 (`private` → `internal`)
- ✅ 슬롯 기반 공통 로직 마무리 완료
  - `ResetNPCProbabilities()`, `ResetBehaviorTreeStates()` 호출 위치 검증 완료
  - 입력 핸들러 바인딩이 슬롯 기반으로 작동함 확인 완료
  - TeamB ActionSelectUI 초기화 추가 완료
- ✅ 회귀 테스트 완료 (시나리오 1, 2 정상 동작 확인)
- ⏳ `Battle` 클래스 분리 예정 (현재는 `BattleState`만 분리됨, 선택사항)

#### 작업 항목

| 작업 | 파일 | 내용 |
|------|------|------|
| Battle 클래스 생성 | Combat/Battle.cs | 전투 관리 클래스 |
| BattleExecutor 생성 | Combat/BattleExecutor.cs | CombatManager 로직 복사 |
| CombatManager 수정 | Combat/CombatManager.cs | Battle 생성 및 실행으로 변경 |
| 테스트 | - | 1:1 전투 동작 확인 |

#### 리팩토링 범위

```
CombatManager (Before)
├─ RunCombat()
├─ PerformTurn()
├─ CalculateDamage()
└─ ... (2000+ 라인)

↓ 분리

Battle (After)
├─ Initialize()
├─ Run()
└─ DetermineVictor()

BattleExecutor (After)
├─ RunBattle()
├─ PerformTurn()
└─ CalculateDamage()
```

**예상 시간: 4-6시간**
