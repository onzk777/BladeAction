# 디버그 패널 설정 가이드

## 개요

DebugPanelController는 여러 정보 패널을 관리하고 전환하는 기능을 제공합니다.  
F3 키로 디버그 패널을 열고, 버튼으로 정보 패널을 전환할 수 있습니다.

---

## Unity 설정

### 1단계: Hierarchy 구조 생성

```
Canvas
└── DebugPanel (Panel UI)
    ├── TabButtons (Horizontal Layout Group)
    │   ├── CombatInfoButton (Button)
    │   └── BTInfoButton (Button)
    │
    ├── CombatInfoPanel (Panel)
    │   └── CombatStatusDisplay (기존 전투 정보)
    │       ├── ...
    │
    └── BTInfoPanel (Panel)
        └── BTMonitorUI (BT 정보)
            ├── GeneralInfoText
            ├── EnemyBTStatusText
            ├── PlayerBTStatusText
            └── HistoryText (ScrollView)
```

### 2단계: DebugPanelController 설정

**DebugPanel GameObject에 DebugPanelController 컴포넌트 추가**

**Inspector 설정**:
```
DebugPanelController
├── Debug Panel: [DebugPanel]  ← 최상위 패널
├── Combat Info Panel: [CombatInfoPanel]  ← 전투 정보 패널
└── BT Info Panel: [BTInfoPanel]  ← BT 정보 패널
```

### 3단계: 버튼 연결

**CombatInfoButton**:
- Button 컴포넌트의 OnClick()에 추가
- DebugPanelController → `ShowCombatInfoPanel()`

**BTInfoButton**:
- Button 컴포넌트의 OnClick()에 추가
- DebugPanelController → `ShowBTInfoPanel()`

## 추가 정보 패널 확장

### 1단계: DebugPanelController.cs 수정

```csharp
[Header("정보 패널 설정")]
[SerializeField] private GameObject combatInfoPanel;
[SerializeField] private GameObject btInfoPanel;
[SerializeField] private GameObject newInfoPanel; // ← 신규 패널 추가

// Awake 메서드에 초기화 추가
private void Awake() 
{
    // ...
    if (newInfoPanel != null)
        newInfoPanel.SetActive(false);
}

// 새 메서드 추가
public void ShowNewInfoPanel()
{
    DeactivateAllInfoPanels();
    
    if (newInfoPanel != null)
    {
        newInfoPanel.SetActive(true);
        Debug.Log($"[DebugPanelController] {newInfoPanel.name} 활성화됨");
    }
}

// DeactivateAllInfoPanels에 추가
private void DeactivateAllInfoPanels()
{
    if (combatInfoPanel != null)
        combatInfoPanel.SetActive(false);
    if (btInfoPanel != null)
        btInfoPanel.SetActive(false);
    if (newInfoPanel != null)  // ← 추가
        newInfoPanel.SetActive(false);
}
```

### 2단계: Unity에서 설정

1. 새 패널 GameObject 생성 (예: AnimationInfoPanel)
2. DebugPanelController Inspector에서 New Info Panel 필드에 연결
3. 새 버튼 생성 (예: AnimationInfoButton)
4. 버튼 OnClick()에 `ShowNewInfoPanel()` 연결

## 현재 구조

### 전투 정보 패널 (CombatInfoPanel)

**포함 내용**:
- HP/Poise 바
- 턴 정보
- 전투 상태
- 타이머

**표시 항목** (CombatStatusDisplay):
- Player/Enemy HP, Poise
- 현재 턴 수
- 공격/방어 턴 표시
- 남은 시간

### BT 정보 패널 (BTInfoPanel)

**포함 내용**:
- 일반 정보 (턴, 공격자)
- Enemy BT 상태 (확률, Override)
- Player BT 상태
- **실행 히스토리** (최근 N개)

**표시 항목** (BTMonitorUI):
- 실시간 확률 모니터링
- BT Override 상태
- 선택된 검술
- 최근 BT 평가 기록

## 동작 원리

### 패널 전환 로직

```csharp
ShowCombatInfoPanel() 호출:
    1. DeactivateAllInfoPanels() → 모든 패널 OFF
    2. combatInfoPanel.SetActive(true) → 전투 정보만 ON

ShowBTInfoPanel() 호출:
    1. DeactivateAllInfoPanels() → 모든 패널 OFF
    2. btInfoPanel.SetActive(true) → BT 정보만 ON
```

**장점**:
- ✅ 한 번에 하나의 패널만 표시
- ✅ 깔끔한 UI
- ✅ 쉬운 확장성
- ✅ 명확한 전환 로직

## 문제 해결

### Q1: 버튼을 눌러도 패널이 전환되지 않음

**확인 사항**:
1. DebugPanelController Inspector에서 패널들이 연결되었는지 확인
2. 버튼의 OnClick()에 올바른 메서드가 연결되었는지 확인
3. Console 로그 확인:
   ```
   [DebugPanelController] 전투 정보 패널 활성화
   [DebugPanelController] CombatInfoPanel 활성화됨
   ```

**해결**:
- Inspector에서 GameObject 드래그 앤 드롭으로 재연결
- 버튼 OnClick() 재설정

### Q2: F3 키가 동작하지 않음

**확인 사항**:
1. Input Actions Asset에 Debug 액션 맵이 있는지 확인
2. DebugPanel 액션이 F3 키로 설정되었는지 확인
3. Console 로그 확인:
   ```
   [DebugPanelController] Debug 액션 맵 활성화 완료
   ```

**해결**:
- Input Actions Asset 확인 및 재설정

### Q3: 패널이 겹쳐서 표시됨

**확인 사항**:
- `DeactivateAllInfoPanels()`에 모든 패널이 포함되었는지 확인

**해결**:
```csharp
// DeactivateAllInfoPanels() 메서드 확인
private void DeactivateAllInfoPanels()
{
    if (combatInfoPanel != null)
        combatInfoPanel.SetActive(false);
    if (btInfoPanel != null)
        btInfoPanel.SetActive(false);
    // 새 패널도 추가해야 함!
}
```
