방어자의 액션 기준 변경
 - 공격자의 타이밍 복제가 아닌 발사체 트리거 기반으로 완벽 입력 기준 변경

판정 시점과 기준 변경
 - 방어자의 액션 입력이 발사체 기준이 되므로, 로직 상 순서가 다소 변경됨.

1.  공격자의 완벽 입력 여부가 입력된 상태. (공격자의 입력이 이루어지면서 발사체가 발사되기 때문에 선행 정의됨)
2.  방어자는 발사체를 기준으로 방어 행동을 하게 됨. 막기 혹은 쳐내기.
2.1.    플레이어, 적 모두 자신을 중심으로 한 2개의 collider 2d 를 가짐. 
2.1.1.  PerfectHitChecker - Trigger 체크용 collider. 
        상대의 공격 발사체가 이 collider 에 trigger 되면, 방어자 입장에서 완벽 입력이 가능해지는 시점이 되어 CharacterHitBox에 trigger 되기 전에 입력에 성공하면 완벽 입력 처리가 되어 즉시 판정이 발생함.
2.1.2.  CharacterHitBox - Trigger 체크용 collider. 
        상대의 공격 발사체가 이 collider 에 trigger 되면 피격 타이밍으로 동작하여 판정이 발생함. 
        방어자가 막기 중이면 막기를 시도한 것으로 간주하여 판정이 발생하는 등. 방어자가 완벽 입력에 성공하여 쳐내기에 성공한게 아닌 이상 피격 적중, 막기 성공, 막기 파괴 등의 판정은 이 때 일어나게 됨. 
2.2.    공격자의 발사체는 공격자의 Trigger 용도 collider 와 충돌하지 않아야 함. 
3.  타격의 전환은 공격 액션 커맨드에 지정된 시간에 이루어지며 이전 타격의 판정과 아무 관련 없이 정상적으로 자신의 타이밍에 이루어질 수 있어야 함. 
4.  턴의 종료는 공격자의 마지막 히트 발사체로 인한 판정이 완료되면 이루어짐. 기존의 턴 종료 딜레이 설정은 동일하게 적용되어야 함. 

# 전투 시스템 개선 - 발사체 구조

## 핵심 원칙

### 히트 전환 로직
- **히트 전환은 시간 기반**: ActionCommandData에 지정된 시간에 따라 전환
- **발사체 발사는 입력 기반**: 완벽 입력 성공 시 즉시, 실패/미입력 시 end 타이밍
- **히트 전환과 발사체 상태는 무관**: 1타 end 타이밍에 즉시 2타로 전환

### 타임라인 예시 (1타: 1.0~1.3초, 2타: 2.0~2.3초)

#### 1타 (1.0초 ~ 1.3초)
- **1.0초**: 1타 입력 시작
- **1.0초~1.3초**: 완벽 입력 대기
  - **완벽 입력 성공**: 즉시 발사체 발사
  - **완벽 입력 실패/미입력**: 1.3초에 발사체 발사
- **1.3초**: **히트 전환** (발사체 상태와 무관)

#### 2타 (2.0초 ~ 2.3초)
- **2.0초**: 2타 입력 시작
- **2.0초~2.3초**: 완벽 입력 대기
  - **완벽 입력 성공**: 즉시 발사체 발사
  - **완벽 입력 실패/미입력**: 2.3초에 발사체 발사
- **2.3초**: **턴 종료** (발사체 상태와 무관)

## 구현 요구사항

### 1. 히트 전환
- **perfectWindowEnd 타이밍에 즉시 전환**
- **발사체 충돌 상태와 무관**

### 2. 발사체 발사
- **ResolveInput에서 처리** (성공/실패 무관)
- **완벽 입력 성공**: 즉시 발사
- **완벽 입력 실패/미입력**: end 타이밍에 발사

### 3. 턴 종료
- **마지막 히트 end 타이밍 + Turn End Buffer 시간**
- **GlobalConfig.TurnEndBuffer 참조**

## 방어자 시스템

### 충돌체 구조
- **PerfectInputArea**: 완벽 입력 가능 시점 (발사체 진입 시)
- **CharacterHitBox**: 피격 타이밍 (발사체 진입 시)

### 판정 로직
1. **공격자 완벽 입력 여부** (발사체 발사 시점에 결정)
2. **방어자 발사체 기반 방어 행동** (막기/쳐내기)
3. **발사체 충돌 시 최종 판정**

### 충돌 방지
- **공격자 발사체는 공격자 충돌체와 충돌하지 않음**
