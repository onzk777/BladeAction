### 1. 중복 판정 문제 ✅ **해결됨**
- **문제**: 발사체가 CharacterHitBox에 충돌할 때마다 판정이 반복 발생
- **해결**: hitJudgmentCompleted[] 배열로 히트당 판정 한 번만 발생하도록 제어
- **상태**: 완전 해결됨

### 2. CurrentHit 범위 초과 문제 ✅ **해결됨**
- **문제**: IndexOutOfRangeException (CurrentHit=2, 배열 길이=2)
- **해결**: 발사체에 hitIndex 필드 추가하여 발사 시점의 히트 인덱스 저장
- **상태**: 완전 해결됨

### 3. 턴 종료 로직 문제 ✅ **해결됨**
- **문제**: 턴 종료 대기 시간이 제대로 동작하지 않음
- **해결**: 시간 기반 턴 종료로 변경 (마지막 히트 end + Turn End Buffer)
- **상태**: 완전 해결됨
