# 리팩토링 테스트 케이스 (2025-10-28)

## 리팩토링 개요

### 변경 사항
- `Combatant` → `Character`
- `CombatantInventory` → `CharacterInventory`
- `PlayerCombatant` → `PlayerCharacter`
- `EnemyCombatant` → `EnemyCharacter`
- `GetEffective*` → `GetFinal*`
- `Map*` → `Convert*`
- `CombatStats` 구조체 확장 (currentHP, currentPoise, tempDRBonus 추가)
- `CharacterData.baseStats` 필드 추가 (CombatStats 타입)

---

## 테스트 케이스

### 1. 기본 구조 검증

#### 1.1 CharacterData 검증
**목적:** CharacterData의 baseStats가 올바르게 설정되는지 확인

**테스트 단계:**
1. Unity 에디터에서 CharacterData 에셋 열기 (예: Player_Warrior.asset)
2. Inspector에서 "기본 전투 스탯" 섹션 확인
3. baseStats 구조체가 표시되는지 확인
4. 값 수정 후 저장

**예상 결과:**
- baseStats 필드가 Inspector에서 보임
- maxHP, attack, defenseDR 등이 정상 표시
- 값 수정 및 저장 가능
- 기존 필드들은 Deprecated 경고 표시

---

#### 1.2 Character 인스턴스 생성 검증
**목적:** Character 인스턴스가 정상 생성되는지 확인

**테스트 코드:**
```csharp
// CharacterManager.cs에서 자동 실행됨
PlayerCharacter = new PlayerCharacter(PlayerData, null);
EnemyCharacter = new EnemyCharacter(EnemyData, null);
```

**예상 결과:**
- Console에 "[Character] XXX 런타임 스테이터스 초기화" 로그
- 에러 없이 생성 완료

---

### 2. 스탯 계산 시스템 검증

#### 2.1 GetFinalStats 테스트
**목적:** 기본 스탯 + 장비 스탯 합산 확인

**테스트 단계:**
1. ProtoType.unity Scene 실행
2. Tools > Stats > Recalculate All Characters (Scene) 실행
3. Console 로그 확인

**예상 결과:**
```
[StatsCalculationManager] Player 스탯 재계산 완료 - 
  ATK:20, MaxHP:100, HP:100, MaxPoise:100
```

**장비 장착 후:**
```
[StatsCalculationManager] Player 스탯 재계산 완료 - 
  ATK:35, MaxHP:120, HP:120, MaxPoise:110
```

---

#### 2.2 RecalculateAndCommit 테스트
**목적:** 장비 변경 시 자동 재계산 확인

**테스트 코드:**
```csharp
var player = CharacterManager.Instance.PlayerCharacter;
player.Inventory = new CharacterInventory();
player.Inventory.Owner = player;
player.Inventory.Initialize();

// 아이템 추가 및 장착
player.Inventory.AddItem("itm_weapon_test", 1);
player.Inventory.EquipItem("itm_weapon_test", EquipmentSlotType.Weapon);

// 자동으로 RecalculateAndCommit 호출됨
```

**예상 결과:**
- "[StatsCalculationManager] Player 스탯 재계산 완료" 로그
- ATK 증가 확인
- CombatStatusDisplay UI 자동 업데이트

---

#### 2.3 HP 비율 보존 테스트
**목적:** 장비 변경 시 HP 비율 유지 확인

**테스트 시나리오:**
```
초기 상태: HP 50/100 (50%)
장비 장착: MaxHP 100 → 120
예상 결과: HP 60/120 (50% 유지)
```

**테스트 코드:**
```csharp
var player = CharacterManager.Instance.PlayerCharacter;
player.currentHP = 50;  // 50% 상태
Debug.Log($"장착 전: HP {player.currentHP}/{player.MaxHP}");

// 장비 장착 (MaxHP +20)
player.Inventory.EquipItem("itm_armor_test", EquipmentSlotType.Armor);

Debug.Log($"장착 후: HP {player.currentHP}/{player.MaxHP}");
// 예상: HP 60/120
```

**예상 결과:**
- HP 비율이 보존됨 (50% → 50%)
- HP 60/120 확인

### 3. 인벤토리 연동 검증

#### 3.1 CharacterInventory 생성 및 초기화
**목적:** CharacterInventory가 정상 작동하는지 확인

**테스트 코드:**
```csharp
var inventory = new CharacterInventory();
var player = CharacterManager.Instance.PlayerCharacter;

inventory.Owner = player;
player.Inventory = inventory;

inventory.Initialize();
```

**예상 결과:**
- 6개 장비 슬롯 생성 확인
- Owner 양방향 참조 확인

---

#### 3.2 아이템 장착/해제 시 스탯 재계산
**목적:** 장착/해제 시 TriggerStatsRecalculation 자동 호출 확인

**테스트 코드:**
```csharp
// 장착
inventory.AddItem("itm_weapon_test", 1);
bool equipped = inventory.EquipItem("itm_weapon_test", EquipmentSlotType.Weapon);
// → RecalculateAndCommit 자동 호출됨

// 해제
bool unequipped = inventory.UnequipItem(EquipmentSlotType.Weapon);
// → RecalculateAndCommit 자동 호출됨
```

**예상 결과:**
- 장착 시: "[StatsCalculationManager] 스탯 재계산 완료" 로그 2번 (장착, 해제)
- ATK 증가/감소 확인
- UI 자동 갱신

### 5. 전투 시스템 검증

#### 5.1 전투 중 스탯 적용
**목적:** 전투 계산에 최종 스탯이 반영되는지 확인

**테스트 단계:**
1. ProtoType.unity 실행
2. 플레이어에게 무기 장착 (ATK +15)

### 7. 마이그레이션 검증

#### 7.1 기존 CharacterData 에셋 호환성
**목적:** 기존 에셋이 정상 로드되는지 확인

**테스트 단계:**
1. 기존 CharacterData 에셋 열기
2. baseStats가 기본값(0)으로 초기화되어 있는지 확인
3. 기존 필드(baseMaxHP 등)가 아직 값을 가지고 있는지 확인
4. 프로퍼티(MaxHP 등)가 정상 작동하는지 확인

**예상 결과:**
- baseStats는 초기값(0)
- 기존 필드는 값 유지
- 프로퍼티는 기존 필드 → baseStats 순으로 참조 (호환성)
- Deprecated 경고 표시

---

#### 7.2 데이터 마이그레이션 도구 실행

**테스트 단계:**
1. Tools > Character > Migrate CharacterData to CombatStats (작성 필요)
2. 모든 CharacterData 에셋 변환
3. baseStats 값 확인

**예상 결과:**
- baseMaxHP → baseStats.maxHP
- baseATK → baseStats.attack
- 모든 값 정상 이전

## 주의사항

### Deprecated 필드
다음 필드들은 현재 deprecated 경고가 발생합니다:
- `CharacterData.guardDRBonus`
- `CharacterData.guardDamageReduction`
- `CharacterData.baseMaxHP`, `baseATK`, `baseDR` 등

**대응:**
- 현재는 호환성을 위해 유지
- 추후 마이그레이션 도구로 일괄 변환
- baseStats로 완전 이전 후 제거

    // ...

- Tools > Stats > Recalculate All Characters (Scene)
- Tools > Stats > Force Update Combat UI

## 예상 이슈 및 해결

### 이슈 1: CharacterData 에셋이 baseStats 값이 0
**원인:** 기존 에셋은 baseStats가 초기화되지 않음
**해결:** 마이그레이션 도구 실행 또는 수동 설정

### 이슈 2: Deprecated 경고 다수 발생
**원인:** 기존 코드가 구형 필드 사용
**해결:** 정상 동작이므로 무시 가능. 추후 일괄 수정

### 이슈 3: Scene에서 Character 참조 깨짐
**원인:** Prefab이나 Scene 파일이 구형 참조 유지
**해결:** Scene 재저장 또는 참조 재연결
