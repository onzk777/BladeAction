# 1차 능력치와 2차 능력치 계산 시스템

## 1. 개요

### 1.1 목적
캐릭터의 능력치를 체계적으로 관리하고, 다양한 외부 요인(장비, 검술, 유파, 지속효과 등)이 능력치에 미치는 영향을 명확하게 분리하여 계산하는 시스템을 구축한다.

### 1.2 핵심 개념
- **1차 능력치**: 캐릭터의 순수한 기본 능력치 (외부 요인 영향 없음)
- **2차 능력치**: 1차 능력치 + 모든 외부 요인의 영향을 받은 실제 전투 능력치
- **능력치 계산 매니저**: 1차 → 2차 능력치 변환을 담당하는 중앙 관리 시스템

## 2. 능력치 데이터 정의

### 2.1 기본 데이터 (Base Data)
플레이어 및 NPC의 초기 데이터를 별도의 데이터로 저장하고 관리하는 시스템

#### 2.1.1 특징
- **변경 불가**: 게임 중에 변경되지 않음
- **데이터 애셋**: ScriptableObject로 관리
- **레벨별 데이터**: 레벨업 시스템을 위한 성장 데이터 포함

#### 2.1.2 구성 요소
- **초기 데이터**: 레벨 1일 때의 기본 스탯
- **레벨별 성장 데이터**: 각 레벨에서의 스탯 성장량 또는 최종 스탯
- **성장 곡선**: 레벨업 시 스탯 성장 공식 (선형, 지수, 구간별 등)

#### 2.1.3 데이터 구조 (예시)
```csharp
[CreateAssetMenu(fileName = "CharacterBaseData", menuName = "Character/Base Data")]
public class CharacterBaseData : ScriptableObject
{
    [Header("기본 정보")]
    public string characterName;
    public CharacterType characterType;
    
    [Header("초기 스탯 (레벨 1)")]
    public int baseHP;
    public int baseATK;
    public int baseDR;
    public int baseCrit;
    public int baseCritRatio;
    public int baseMaxPoise;
    public int baseParryPoiseDamage;
    
    [Header("레벨별 성장 데이터")]
    public LevelGrowthData[] levelGrowthData;
    
    [Header("성장 곡선 설정")]
    public GrowthCurveType growthCurveType;
    public AnimationCurve growthCurve;
}

[System.Serializable]
public class LevelGrowthData
{
    public int level;
    public int hpGrowth;
    public int atkGrowth;
    public int drGrowth;
    public int critGrowth;
    public int critRatioGrowth;
    public int maxPoiseGrowth;
    public int parryPoiseDamageGrowth;
}

public enum GrowthCurveType
{
    Linear,     // 선형 성장
    Exponential, // 지수 성장
    Custom      // 커스텀 곡선
}
```

### 2.2 1차 데이터 (Primary Data)
기본 데이터를 참조해 생성된 Combatant의 능력치가 레벨업 등의 요인으로 인해 변경된 "현재 상태"의 맨몸 스테이터스 데이터

#### 2.2.1 특징
- **런타임 데이터**: 데이터 애셋으로 관리되지 않음
- **현재 상태**: 레벨업으로 성장한 현재 스탯
- **맨몸 상태**: 장비나 외부 요인 없이 순수 캐릭터 능력치

#### 2.2.2 데이터 흐름
```
기본 데이터 (ScriptableObject)
├── 초기 데이터 (레벨 1)
├── 레벨별 성장 데이터
└── 성장 곡선 공식
    ↓
1차 데이터 (런타임)
├── 현재 레벨
├── 현재 스탯 (기본 데이터 + 레벨 성장)
└── 임시 상태 (HP, Poise 등)
```

### 2.3 2차 데이터 (Secondary Data)
1차 데이터에 모든 외부 요인의 영향을 적용한 실제 전투에서 사용되는 능력치

#### 2.3.1 계산 공식
```
2차 능력치 = 1차 능력치 + 장비 보너스 + 검술/유파 보너스 + 전투 중 지속효과
```

#### 2.3.2 계산 순서
1. **1차 능력치** (기본값)
2. **장비 보너스** (추후 구현)
3. **검술/유파 보너스** (추후 구현)
4. **전투 중 지속효과** (현재 구현됨, 가장 마지막)

#### 2.3.3 능력치 종류
- **생존 능력치**: HP, MaxHP, MaxPoise
- **공격 능력치**: ATK, Crit, CritRatio, PerfectChance
- **방어 능력치**: DR, ParryPoiseDamage

## 3. 능력치 계산 매니저 (StatsCalculationManager)

### 3.1 역할
- 1차 능력치를 기반으로 2차 능력치를 계산
- 다양한 외부 요인들의 영향을 순차적으로 적용
- 능력치 변경 시 이벤트 발생으로 UI 업데이트

### 3.2 주요 기능

#### 3.2.1 능력치 계산
```csharp
public class StatsCalculationManager
{
    // 1차 능력치 → 2차 능력치 변환
    public int CalculateEffectiveATK(Combatant combatant);
    public int CalculateEffectiveDR(Combatant combatant);
    public int CalculateEffectiveCrit(Combatant combatant);
    public int CalculateEffectiveCritRatio(Combatant combatant);
    public int CalculateEffectiveMaxHP(Combatant combatant);
    public int CalculateEffectiveMaxPoise(Combatant combatant);
    public int CalculateEffectivePerfectChance(Combatant combatant);
}
```

#### 3.2.2 계산 순서 관리
```csharp
public enum StatModifierType
{
    Equipment,      // 장비
    SwordArt,       // 검술/유파
    DurationalEffect // 지속효과 (가장 마지막)
}
```

#### 3.2.3 이벤트 시스템
```csharp
public event Action<Combatant> OnStatsCalculated;
public event Action<Combatant, StatType> OnSpecificStatChanged;
```

### 3.3 구현 구조

#### 3.3.1 클래스 구조
```csharp
public class StatsCalculationManager : MonoBehaviour
{
    // 싱글톤 패턴
    public static StatsCalculationManager Instance { get; private set; }
    
    // 능력치 계산 메서드들
    public int GetEffectiveATK(Combatant combatant);
    public int GetEffectiveDR(Combatant combatant);
    // ... 기타 능력치들
    
    // 외부 요인 등록/해제
    public void RegisterModifier(Combatant combatant, StatModifierType type, StatModifier modifier);
    public void UnregisterModifier(Combatant combatant, StatModifierType type, string modifierId);
    
    // 능력치 재계산
    public void RecalculateStats(Combatant combatant);
}
```

#### 3.3.2 수정자 시스템
```csharp
[System.Serializable]
public class StatModifier
{
    public string modifierId;
    public StatType statType;
    public int value;
    public StatModifierType sourceType;
    public int priority; // 계산 순서 (낮을수록 먼저)
}
```

## 4. 기존 시스템과의 통합

### 4.1 DurationalEffect 시스템 통합
- 기존 `DurationalEffectManager`는 `StatsCalculationManager`의 하위 시스템으로 통합
- 지속효과는 `StatModifierType.DurationalEffect`로 분류
- 가장 마지막 우선순위로 계산

### 4.2 CharacterData 리팩토링
- 1차 능력치만 저장하도록 수정
- 2차 능력치는 `StatsCalculationManager`를 통해 계산
- 기존 `GetEffectiveXXX()` 메서드들은 `StatsCalculationManager`로 위임

### 4.3 Combatant 클래스 수정
- `GetEffectiveXXX()` 메서드들이 `StatsCalculationManager`를 호출하도록 수정
- 능력치 변경 시 자동으로 재계산되도록 이벤트 구독

## 5. 확장성 고려사항

### 5.1 장비 시스템 (추후 구현)
- 장비 아이템이 능력치에 미치는 영향
- 장비 착용/해제 시 능력치 재계산
- 장비 세트 효과

### 5.2 검술/유파 시스템 (추후 구현)
- 검술 유파별 능력치 보너스
- 특정 검술 사용 시 임시 능력치 변화
- 유파 전환 시 능력치 재계산

### 5.3 레벨업 시스템 (추후 구현)
- 1차 능력치의 성장
- 레벨업 시 모든 2차 능력치 자동 재계산
- 성장 포인트 분배 시스템
