# 리팩토링 테스트 케이스

## 📋 문서 목적
`Combatant` → `Character` 리팩토링 및 `CombatStats` 시스템 통합 후, **Unity 에디터에서 실제로 기능이 정상 작동하는지 검증**합니다.

이 문서는 **구현 지시서가 아니라 검증 절차서**입니다.

---

## 🎮 테스트 환경
- **Scene**: ProtoType.unity
- **필요 컴포넌트**: CharacterManager, StatsCalculationManager, InventoryUI, PlayerInput

---

## ✅ 테스트 체크리스트

### 1단계: Scene 초기 설정 확인

#### ✓ 1.1 필수 GameObject 존재 확인
**절차:**
1. ProtoType.unity Scene 열기
2. Hierarchy에서 확인:
   - [v] CharacterManager GameObject 있음
   - [v] InventoryCanvas (또는 InventoryUI가 있는 GameObject) 있음
   - [v] PlayerInput 컴포넌트가 있는 GameObject 있음

**통과:** 모든 체크박스 ✅

---

#### ✓ 1.2 CharacterManager 설정 확인
**절차:**
1. CharacterManager GameObject 선택
2. Inspector 확인:
   - [v] Player Data Asset 필드에 ScriptableObject 할당됨
   - [v] Enemy Data Asset 필드에 ScriptableObject 할당됨

**통과:** 두 필드 모두 할당됨

---

### 2단계: Character 초기화 확인

#### ✓ 2.1 Play 모드 진입 시 Character 생성 확인
**절차:**
1. Console 창 열기 (Ctrl+Shift+C)
2. **Play 버튼** 클릭
3. Console 로그 확인

**예상 로그:**
```
[CharacterManager] CharacterData, BT 인스턴스화 및 Character 초기화 완료.
[Character] Player 런타임 스테이터스 초기화
[Character] Enemy 런타임 스테이터스 초기화
```

**통과:** 위 로그들이 순서대로 출력되고 에러 없음

---

#### ✓ 2.2 Character 인스턴스 상태 확인
**절차:**
1. Play 모드 유지
2. CharacterManager GameObject 선택
3. Inspector에서 **Debug 모드** 활성화 (우측 상단 ⋮ 메뉴 → Debug)
4. CharacterManager 필드 확인:
   - [v] PlayerCharacter 필드가 null이 아님
   - [v] EnemyCharacter 필드가 null이 아님

**통과:** 두 필드 모두 객체 인스턴스가 존재함

---

### 3단계: Inventory 시스템 확인

#### ✓ 3.1 Character Inventory 자동 할당 확인
**현재 상태:** ✅ **구현 완료**

**절차:**
1. Play 모드 진입
2. Console 로그 확인

**예상 로그:**
```
[CharacterManager] Player Inventory 생성 완료
[CharacterManager] Player Inventory 초기화 완료 - Inventory: 0/5000 slots used, Equipment: 0/6 slots equipped
[CharacterManager] Enemy Inventory 생성 완료
[CharacterManager] Enemy Inventory 초기화 완료 - Inventory: 0/5000 slots used, Equipment: 0/6 slots equipped
```

**통과:** 위 로그 출력 + 에러 없음

---

#### ✓ 3.2 CharacterData 초기 인벤토리 설정 확인
**목적:** Inspector에서 CharacterData에 초기 아이템/장비를 설정할 수 있는지 확인

**절차:**
1. Project 창에서 PlayerData 또는 EnemyData 선택
2. Inspector 확인:
   - [v]"초기 인벤토리" 섹션 존재
   - [v] "Initial Items" 리스트 존재 (아이템 ID + 수량)
   - [v] "Initial Equipment" 리스트 존재 (슬롯 + 아이템 ID)

**통과:** 위 섹션들이 Inspector에 표시됨

---

#### ✓ 3.3 초기 장비 자동 장착 확인
**전제:** CharacterData에 initialEquipment를 설정해야 함

**절차:**
1. PlayerData 에셋 열기
2. Initial Equipment에 테스트 장비 추가:
   - Slot Type: Weapon
   - Item Id: "itm_weapon_test" (ItemDatabase에 존재하는 ID)
3. Save
4. Play 모드 진입
5. Console 로그 확인

**예상 로그:**
```
[CharacterManager] Player 초기 장비 장착: itm_weapon_test → Weapon
[StatsCalculationManager] Player 스탯 재계산 완료 - ATK:35, MaxHP:100, HP:100, MaxPoise:100
```

**통과:** 장비가 자동으로 장착되고 스탯이 재계산됨

---

### 4단계: InventoryUI 동작 확인

#### ✓ 4.1 InventoryTestManager 비활성화 확인
**목적:** TestMode = false일 때 정상 동작하는지 확인

**절차:**
1. Scene에서 InventoryTestManager GameObject 선택
2. Inspector에서 **Test Mode** 체크 해제 (false)
3. Play 모드 진입
4. Console 로그 확인

**예상 로그:**
```
[InventoryTestManager] TestMode가 비활성화되어 있습니다. 스크립트 비활성화.
[InventoryUI] UI Action Map 활성화됨 (인벤토리 토글 키 사용 가능)
[InventoryUI] PlayerCharacter.Inventory 자동 연결 완료
```

**통과:** InventoryUI가 PlayerCharacter.Inventory에 자동 연결됨

---

#### ✓ 4.2 InventoryTestManager 활성화 확인 (선택적)
**목적:** TestMode = true일 때 테스트 인벤토리로 동작하는지 확인

**절차:**
1. InventoryTestManager의 **Test Mode** 체크 (true)
2. Play 모드 진입
3. Console 로그 확인

**예상 로그:**
```
[InventoryTestManager] TestMode 활성화 - 테스트 인벤토리로 초기화
[InventoryUI] Inventory가 이미 할당되어 있습니다. (Owner: Unknown)
```

**통과:** InventoryUI가 테스트 인벤토리로 초기화됨 (PlayerCharacter 아님)

---

#### ✓ 4.3 B 키로 인벤토리 토글 확인
**전제:** 
- InventoryTestManager.TestMode = false
- PlayerInput의 ToggleInventory 이벤트가 InventoryUI.TogglePanel()에 연결됨

**절차:**
1. Play 모드 진입
2. Game View 클릭 (입력 활성화)
3. **B 키** 누르기
4. Console 로그 및 화면 확인
5. 인벤토리에 PlayerCharacter의 아이템이 표시되는지 확인

**예상 결과:**
- Console 로그:
  ```
  [InventoryUI] TogglePanel 호출됨!
  [InventoryUI] 패널 열기
  ```
- Game View에 인벤토리 패널이 나타남
- PlayerCharacter.CharacterData의 initialItems/initialEquipment가 표시됨
- 다시 B 키 누르면 패널이 사라짐

**통과:** 
- ✅ 인벤토리가 B 키로 열고 닫힘
- ✅ PlayerCharacter의 데이터가 표시됨 (테스트 데이터 아님)

---

### 5단계: 스탯 계산 시스템 확인

#### ⚠️ 5.1 GetFinalStats 기본 테스트
**전제:** Character에 Inventory가 할당되어 있어야 함

**절차:**
1. Play 모드에서 Console 창 열기
2. 임시 테스트 스크립트를 Scene에 추가:

```csharp
using UnityEngine;

public class StatsTest : MonoBehaviour
{
    void Start()
    {
        var player = CharacterManager.Instance.PlayerCharacter;
        var stats = StatsCalculationManager.Instance.GetFinalStats(player);
        
        Debug.Log($"[StatsTest] Player Final Stats:");
        Debug.Log($"  ATK: {stats.attack}");
        Debug.Log($"  MaxHP: {stats.maxHP}");
        Debug.Log($"  CurrentHP: {stats.currentHP}");
    }
}
```

3. Play 모드 진입
4. Console 로그 확인

**예상 로그:**
```
[StatsTest] Player Final Stats:
  ATK: 20 (CharacterData의 baseStats 값)
  MaxHP: 100
  CurrentHP: 100
```

**통과:** 장비 없을 때 기본 스탯만 출력됨

---

#### ⚠️ 5.2 장비 장착 시 스탯 증가 확인
**전제:** 
- Character에 Inventory가 할당되어 있어야 함
- ItemDatabase에 테스트용 무기 아이템이 등록되어 있어야 함

**절차:**
1. 위 StatsTest 스크립트 수정:

```csharp
void Start()
{
    var player = CharacterManager.Instance.PlayerCharacter;
    
    // 장착 전
    int beforeATK = StatsCalculationManager.Instance.GetFinalATK(player);
    Debug.Log($"[StatsTest] 장착 전 ATK: {beforeATK}");
    
    // 아이템 추가 및 장착
    player.Inventory.AddItem("itm_weapon_test", 1);
    player.Inventory.EquipItem("itm_weapon_test", EquipmentSlotType.Weapon);
    
    // 장착 후
    int afterATK = StatsCalculationManager.Instance.GetFinalATK(player);
    Debug.Log($"[StatsTest] 장착 후 ATK: {afterATK} (증가: +{afterATK - beforeATK})");
}
```

2. Play 모드 진입
3. Console 로그 확인

**예상 로그:**
```
[StatsCalculationManager] Player 스탯 재계산 완료 - ATK:35, MaxHP:100, HP:100
[StatsTest] 장착 전 ATK: 20
[StatsTest] 장착 후 ATK: 35 (증가: +15)
```

**통과:** ATK가 증가함 (아이템 스탯만큼)

---

### 6단계: InventoryUI 통합 테스트

#### ⚠️ 6.1 UI를 통한 아이템 장착 확인
**전제:**
- Character에 Inventory가 할당되어 있어야 함
- InventoryUI.Initialize(player.Inventory)가 호출되어 있어야 함

**절차:**
1. Play 모드 진입
2. B 키로 인벤토리 열기
3. 아이템 슬롯 확인 (비어 있어야 함)
4. Console에서 수동으로 아이템 추가 (또는 테스트 버튼 사용):
   ```
   CharacterManager.Instance.PlayerCharacter.Inventory.AddItem("itm_weapon_test", 1)
   ```
5. 인벤토리 UI에서 아이템이 보이는지 확인
6. 아이템을 장비 슬롯으로 드래그 앤 드롭
7. Console 로그 및 CombatStatusDisplay UI 확인

**예상 결과:**
- 아이템이 장비 슬롯에 장착됨
- Console: `[StatsCalculationManager] Player 스탯 재계산 완료`
- CombatStatusDisplay에 ATK 값이 증가된 것으로 표시됨

**통과:** UI 조작으로 장비 변경 시 스탯이 즉시 반영됨

## 🚨 미해결 이슈

### 🟡 낮은 우선순위
1. **테스트용 아이템 데이터 준비**
   - 스탯 테스트를 위한 무기/방어구 아이템 필요
   - ItemDatabase에 테스트용 아이템 등록 필요

---

## ✅ 해결된 이슈
- ✅ Character Inventory 자동 할당 → CharacterManager.InitializeInventory() 구현
- ✅ InventoryUI 자동 초기화 → InventoryUI.AutoConnectToPlayerInventory() 구현
- ✅ CharacterData 초기 인벤토리 정의 → initialItems, initialEquipment 추가

---

## 📝 테스트 완료 기준

모든 체크리스트 항목이 ✅ 통과되고, **높은/중간 우선순위 미해결 이슈가 없을 때** 리팩토링이 완료된 것으로 간주합니다.
