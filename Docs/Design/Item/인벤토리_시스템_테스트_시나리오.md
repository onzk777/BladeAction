# 인벤토리 시스템 테스트 시나리오

## 📋 **테스트 개요**

### **목적**
인벤토리 시스템의 핵심 기능들을 단계별로 검증하여 UI와 로직의 정상 작동을 확인합니다.

### **테스트 환경**
- **테스트 매니저**: `InventoryTestManager` 컴포넌트
- **테스트 아이템**: 실제 데이터베이스의 아이템 사용
- **UI 시스템**: Prefab 기반 인벤토리 UI

---

## 🎯 **1단계: 기본 설정 및 초기화**

### **목표**
시스템 초기화와 기본 설정이 정상적으로 작동하는지 확인

### **테스트 절차**
1. **InventoryTestManager 컴포넌트 확인**
   - Scene에 `InventoryTestManager` 오브젝트 존재
   - `InventoryUI` 참조 연결됨

2. **초기화 로그 확인**
   ```
   ✅ InventoryUI 초기화 완료
   ✅ 테스트 인벤토리 생성 완료
   ```

3. **기본 상태 확인**
   - 인벤토리 그리드: 빈 슬롯들만 표시
   - 장비 슬롯: 빈 상태로 표시
   - 검술 유파 슬롯: 빈 상태로 표시

### **예상 결과**
- 모든 초기화 로그가 정상 출력
- UI가 빈 상태로 표시됨
- 오류나 경고 없음

---

## 🎯 **2단계: 아이템 추가 및 표시**

### **목표**
아이템이 인벤토리에 정상적으로 추가되고 UI에 표시되는지 확인

### **테스트 절차**
1. **테스트 아이템 추가**
   - `InventoryTestManager` 우클릭 → **"테스트 아이템 추가"** 실행

2. **로그 확인**
   ```
   ✅ 테스트 아이템 추가 완료
   인벤토리 아이템 수: 2
   아이템: 테스트용 직검 (키: itm_weapon_test1, 수량: 1)
   아이템: 테스트용 직검 (키: itm_weapon_test2, 수량: 1)
   ```

3. **UI 표시 확인**
   - 인벤토리 그리드에 아이템 아이콘 표시
   - 아이템 수량 표시 (1개)
   - 아이템 이름 표시

### **예상 결과**
- 아이템 정보 로그가 정상 출력
- 인벤토리 그리드에 아이템이 시각적으로 표시됨
- 아이템 클릭 시 상세 정보 패널 표시

---

## 🎯 **3단계: 아이템 상세 정보 및 장착**

### **목표**
아이템 상세 정보 표시와 장착 기능이 정상 작동하는지 확인

### **테스트 절차**
1. **아이템 클릭**
   - 인벤토리 그리드에서 아이템 클릭

2. **상세 정보 패널 확인**
   - 아이템 아이콘, 이름, 설명 표시
   - 스탯 정보 표시 (있다면)
   - **"장착"** 버튼 표시

3. **장착 테스트**
   - **"장착"** 버튼 클릭
   - 장비 슬롯에 아이템 표시
   - 인벤토리에서 아이템 제거 (장착됨)

### **예상 결과**
- 상세 정보 패널이 정상 표시됨
- 장착 버튼 클릭 시 아이템이 장비 슬롯으로 이동
- 인벤토리에서 해당 아이템이 사라짐

---

## 🎯 **4단계: 장비 해제 및 재장착**

### **목표**
장비 해제와 재장착 기능이 정상 작동하는지 확인

### **테스트 절차**
1. **장비 슬롯 클릭**
   - 장착된 아이템이 있는 슬롯 클릭

2. **해제 확인**
   - 아이템이 인벤토리로 돌아감
   - 장비 슬롯이 빈 상태로 변경

3. **재장착 테스트**
   - 다른 아이템으로 재장착 테스트
   - 장비 교체 기능 확인

### **예상 결과**
- 장비 해제 시 아이템이 인벤토리로 돌아감
- 재장착이 정상적으로 작동함
- 장비 교체 시 이전 장비가 인벤토리로 돌아감

---

## 🎯 **5단계: 검술 유파 시스템**

### **목표**
검술 유파 장착과 하위 검술 목록 표시 기능 확인

### **테스트 절차**
1. **검술 유파 아이템 추가**
   - 검술 유파 아이템을 인벤토리에 추가

2. **유파 장착**
   - 검술 유파 아이템을 검술 유파 슬롯에 장착

3. **하위 검술 목록 확인**
   - 장착된 유파의 검술 목록이 표시됨
   - 각 검술의 이름과 태그 표시

### **예상 결과**
- 검술 유파가 정상적으로 장착됨
- 하위 검술 목록이 UI에 표시됨
- 검술 정보가 정확하게 표시됨

---

## 🎯 **6단계: 장신구 시스템**

### **목표**
장신구의 특별한 표시 방식이 정상 작동하는지 확인

### **테스트 절차**
1. **장신구 아이템 추가**
   - 장신구 아이템을 인벤토리에 추가

2. **장신구 장착**
   - 장신구를 장신구 슬롯에 장착

3. **장신구 표시 확인**
   - 장신구 패널에 가로로 배치됨
   - 이름이 숨겨지고 아이콘만 표시됨

### **예상 결과**
- 장신구가 별도 패널에 가로로 배치됨
- 장신구 이름이 숨겨지고 아이콘만 표시됨
- 장신구 슬롯이 3개까지 정상 작동함

---

## 🎯 **7단계: 이벤트 시스템**

### **목표**
아이템 추가/제거/장착 시 이벤트가 정상적으로 발생하는지 확인

### **테스트 절차**
1. **아이템 추가 이벤트**
   - 아이템 추가 시 UI가 자동으로 갱신되는지 확인

2. **장착 이벤트**
   - 장착 시 관련 UI가 자동으로 갱신되는지 확인

3. **수량 변경 이벤트**
   - 아이템 수량 변경 시 UI 갱신 확인

### **예상 결과**
- 모든 아이템 관련 작업 시 UI가 자동으로 갱신됨
- 이벤트 로그가 정상적으로 출력됨
- 수동 갱신 없이도 UI가 최신 상태 유지

---

## 🎯 **8단계: 통합 테스트**

### **목표**
전체 시스템이 통합적으로 정상 작동하는지 확인

### **테스트 절차**
1. **복합 시나리오**
   - 여러 아이템을 동시에 관리
   - 장비 교체와 인벤토리 정리
   - 검술 유파와 장신구 동시 사용

2. **성능 테스트**
   - 많은 아이템 추가/제거
   - UI 반응성 확인

3. **오류 처리**
   - 잘못된 아이템 키 처리
   - 중복 장착 방지
   - 인벤토리 용량 초과 처리

### **예상 결과**
- 모든 기능이 정상적으로 작동함
- 성능 문제 없이 부드럽게 작동함
- 오류 상황에서도 안정적으로 처리됨

## 🚨 **문제 해결 가이드**

### **자주 발생하는 문제**

1. **아이템이 표시되지 않음**
   - 아이템 키가 데이터베이스와 일치하는지 확인
   - ItemDatabase가 Resources 폴더에 있는지 확인

2. **UI가 갱신되지 않음**
   - ItemEvents 이벤트 구독 확인
   - 수동으로 RefreshAll() 호출

3. **장착이 되지 않음**
   - EquipmentSlotType 확인
   - 아이템 타입과 슬롯 타입 매칭 확인

4. **Prefab 연결 오류**
   - 스크립트 필드 참조 확인
   - Prefab 구조 확인

### **디버그 명령어**
- `InventoryTestManager` 우클릭 → **"디버그 정보 출력"**
- 콘솔에서 상세 로그 확인
- Unity Inspector에서 참조 연결 상태 확인
