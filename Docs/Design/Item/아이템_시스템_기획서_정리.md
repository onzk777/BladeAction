## 1. 시스템 개요

### 1.1 목적
아이템 시스템은 플레이어의 성장과 전략적 선택을 지원하는 핵심 시스템으로, 게임의 재미와 깊이를 제공합니다.

### 1.2 범위
- **장비 아이템**: 무기, 방어구, 보조장비
- **검술 유파**: 전투 스타일 결정 (검술 설정 화면에서 관리)
- **인벤토리 관리**: 저장, 정렬, 검색, 필터링
- **장착 시스템**: 아이템 장착/탈착 및 스탯 적용

### 1.3 핵심 가치
- **직관성**: 쉬운 이해와 사용
- **전략성**: 다양한 조합을 통한 전략적 선택
- **수집성**: 아이템 수집의 재미와 성취감
- **확장성**: 새로운 타입과 기능의 쉬운 추가

## 2. 핵심 설계 철학

### 2.1 무기 중심의 전투 정체성
무기는 게임의 정체성을 나타내는 가장 중요한 장비입니다. 무기 타입에 따라 전투 스타일이 명확히 구분되며, 플레이어는 무기를 통해 자신의 전투 방식을 표현할 수 있습니다.

**설계 원칙:**
- 무기 타입별 고유한 특성 부여
- 플레이어가 무기를 보는 것만으로도 전투 스타일 예측 가능
- 전략적 깊이와 직관성의 균형

### 2.2 방어구의 역할 재정의
방어구는 전투 밸런스보다는 시각적 스타일링과 기본 생존 스펙 향상에 중점을 둡니다.

**설계 원칙:**
- HP와 Poise 등 기본 생존 스탯 향상
- 시각적 스타일링의 역할 (의상 + 모자 등)
- 수집의 재미와 보상 설계 단순화

### 2.3 보조장비의 편의성 제공
보조장비는 전투의 핵심이 아닌 편의성과 세부 성능 조정에 집중합니다.

**설계 원칙:**
- '편안함' 옵션 제공
- 시각적 표시 없이도 타입 정의만으로 충분
- 플레이어의 세부 전략 완성

## 3. 아이템 분류 및 역할

### 3.1 무기 (Weapon) - 게임의 정체성

#### 기본 특성
- **역할**: 공격력과 전투 스타일 결정
- **중요도**: 가장 중요한 장비
- **특징**: 무기 타입에 따라 전투 스타일 명확히 구분

#### 무기 타입별 특성
| 무기 타입 | 공격력 | 막기 성능 | 쳐내기 성능 | 특수 효과 |
|-----------|--------|-----------|-------------|-----------|
| **일본도** | 높음 | 낮음 | Poise 소모 있음 | - |
| **직검** | 균형 | 보통 | Poise 소모 없음 | - |
| **레이피어** | 보통 | 낮음 | 낮음 | 완벽한 공격 시 추가 피해 |
| **대검** | 좋음 | 매우 좋음 | 불가능/낮음 | - |

### 3.2 방어구 (Armor) - 스타일링과 기본 스펙

#### 기본 특성
- **역할**: 스타일링과 기본 생존 스펙 향상
- **중점**: 전투 밸런스보다는 시각적 표현
- **특징**: 다양한 조합을 통한 수집의 재미

#### 설계 방향
- HP와 Poise 등 기본 생존 스탯 향상
- 시각적 스타일링의 역할
- 수집의 재미와 보상 설계 단순화

### 3.3 보조장비 (Accessory) - 편의성 옵션

#### 기본 특성
- **역할**: 편의성과 세부 성능 조정
- **특징**: 여러 개 장착 가능
- **예시**: 튼튼한 가죽 끈으로 막기 피해 감소 약간 증가

#### 설계 방향
- '편안함' 옵션 제공
- 시각적 표시 없이도 타입 정의만으로 충분
- 플레이어의 세부 전략 완성

### 3.4 검술 유파 (Swordplay Style) - 검술 설정 화면 통합

#### 기본 특성
- **역할**: 전투 기술과 액션 패턴 결정
- **관리**: 검술 설정 화면에서 통합 관리
- **특징**: 독자 검술과 유파 검술의 조합

#### 검술 설정 화면 기능
- 장착할 유파 선택
- 사용할 검술 설정 (4개 슬롯)
- 독자 검술과 유파 검술 조합 가능

## 4. 게임플레이 경험

### 4.1 플레이어 경험 목표

#### 핵심 경험
- **수집의 재미**: 다양한 아이템 발견과 획득
- **성장의 만족감**: 강력한 아이템 장착을 통한 성능 향상
- **전략적 선택**: 상황에 맞는 아이템 조합 선택
- **개성 표현**: 플레이어만의 독특한 아이템 조합
- **숙련을 통한 성장**: 무기 타입 숙련도를 통한 진정한 '대가' 경험

#### 게임플레이 루프
1. **탐험** → 2. **획득** → 3. **분석** → 4. **선택** → 5. **적용** → 6. **숙련** → 7. **반복**

### 4.2 숙련도 시스템과의 연계

#### 무기 타입 숙련
- 특정 무기 타입 지속 사용 시 숙련도 증가
- 플레이어의 성장감과 능숙함 체감
- 장기적인 플레이 목표 제시

#### 무형의 경지
- 각 무기 타입 숙련도 최종 단계 도달 시 해금
- 해당 무기 타입을 요구하는 검술 유파를 어떤 무기로도 사용 가능
- 전투 스타일에 대한 유연성과 전략적 깊이 제공

### 4.3 인벤토리 시스템 의도

#### 수집의 재미
- 다양한 타입과 등급의 아이템 제공
- 희귀한 아이템의 가치와 획득 만족감
- 세트 아이템이나 조합 아이템의 완성 목표

#### 관리의 편의성
- 아이템 타입별 명확한 분류
- 빠른 검색과 필터링 기능
- 다양한 기준의 정렬 옵션

#### 전략적 선택
- 아이템 간 성능 비교
- 장착 전 성능 미리보기
- 상황별 아이템 세트 관리

## 5. 시스템 통합 및 연계

### 5.1 검술 설정 화면의 통합 관리

#### 통합된 사용자 경험
- 검술 유파 선택과 검술 조합 설정을 하나의 화면에서 처리
- 플레이어의 혼란 감소와 효율성 향상
- 직관적인 인터페이스 제공

#### 독자 검술과 유파 검술의 조합
- 4개의 검술 슬롯에 자유로운 조합 가능
- 독자 검술: 무기 타입에 관계없이 사용 가능
- 유파 검술: 선택한 유파에서 제공
- 다양한 전투 스타일의 조합 가능

### 5.2 데이터 관리 전략

#### 하이브리드 데이터 관리
- **Unity Asset**: ScriptableObject 참조, 2D Sprite, 사운드 등
- **Excel 데이터**: 텍스트 데이터, 수치 데이터, 설정값 등
- **itemKey**: Excel에서 관리하되 Unity에서도 자주 확인/참조

#### 개발 효율성
- 기획자와 프로그래머의 효율적 협업
- 대량 아이템 데이터 효율적 관리
- 여러 아이템의 공통 속성 일괄 수정

## 10. 결론

아이템 시스템은 게임의 핵심 재미 요소로, 플레이어의 성장과 전략적 선택을 지원하는 중요한 시스템입니다. 무기 중심의 전투 정체성, 방어구의 스타일링 역할, 보조장비의 편의성 제공, 그리고 검술 유파의 통합 관리를 통해 직관적인 사용성과 깊이 있는 전략성을 동시에 제공합니다.

이 시스템을 통해 플레이어는 자신만의 독특한 캐릭터를 만들고, 다양한 전략을 시도하며, 지속적인 성장의 만족감을 느낄 수 있을 것입니다. 동시에 개발팀은 효율적으로 대량의 아이템 데이터를 관리하고, 지속적으로 시스템을 개선해 나갈 수 있을 것입니다.
