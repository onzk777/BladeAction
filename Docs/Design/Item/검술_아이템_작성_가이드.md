# 검술 아이템 작성 가이드

## 1. 개요

이 가이드는 새로운 검술(ActionCommand)을 아이템으로 만드는 방법을 설명합니다.

### 전제 조건
- ActionCommandData SO가 이미 존재해야 함
- ItemDatabase 시스템에 대한 기본 이해

---

## 2. 검술 아이템 생성 절차

### 2.1 ActionCommandData 준비 (선행 작업)

검술 아이템을 만들기 전에 먼저 ActionCommandData SO가 있어야 합니다.

**위치**: `Assets/Resources/Data/ActionData/`

**생성 방법**:
1. Project 창에서 `Assets/Resources/Data/ActionData` 폴더로 이동
2. 우클릭 → `Create > Combat > ActionCommandData`
3. 파일명 설정 (예: `BasicSlash`)
4. Inspector에서 검술 정보 설정:
   - `commandName`: 표시 이름 (예: "기본 베기")
   - `animationName`: Spine 애니메이션 이름
   - `perfectTimings`: 히트 타이밍 설정
   - `damageRatio`: 공격력 배율
   - 기타 검술 고유 속성

---

### 2.2 Item SO 생성

**위치**: `Assets/Resources/Data/Items/Actions/` (권장)

**생성 방법**:
1. Project 창에서 `Assets/Resources/Data/Items/Actions` 폴더로 이동
   - 폴더가 없으면 생성
2. 우클릭 → `Create > Item > Item` (또는 ScriptableObject 메뉴에서)
3. 파일명 설정 (예: `BasicSlash_Item`)

---

### 2.3 Item 필드 설정

Inspector에서 다음 필드를 설정합니다:

#### 기본 정보
```
itemKey: "action_basic_slash"
  └─ 고유 키, 중복 불가
  └─ 규칙: "action_" 접두사 권장

itemName: "기본 베기"
  └─ 게임 내 표시 이름

description: "기본적인 베기 공격입니다."
  └─ 검술 설명

itemType: ActionCommand
  └─ 드롭다운에서 선택

requiredLevel: 1
  └─ 필요 레벨 (선택)

maxStack: 1
  └─ 검술은 중첩 불가, 항상 1
```

#### Unity Asset 참조
```
icon: [아이콘 스프라이트 할당]
  └─ 검술 아이콘 이미지

appearance: (선택)
  └─ 전투 중 표시 외형 (필요시)
```

#### 검술 데이터
```
actionCommandData: [ActionCommandData SO 할당]
  └─ 2.1에서 생성한 ActionCommandData를 드래그 앤 드롭
  └─ 예: BasicSlash
```

#### 스탯 설정
```
useStatTable: 체크 해제
  └─ 검술은 스탯 테이블 사용 안 함
```

---

### 2.4 ItemDatabase 등록

생성한 Item SO를 ItemDatabase에 등록해야 게임에서 사용할 수 있습니다.

**방법 1: ItemDatabase SO에 직접 추가**
1. `Assets/Resources/Data/ItemDatabase` 열기
2. Inspector에서 `Items` 리스트 확장
3. `+` 버튼으로 새 항목 추가
4. 생성한 Item SO를 드래그 앤 드롭

**방법 2: CSV를 통한 등록** (선택)
- ItemTable CSV에 검술 아이템 행 추가
- CSV Import 기능으로 자동 등록

## 3. 검증 체크리스트

아이템 생성 후 다음 사항을 확인하세요:

- [ ] `itemKey`가 고유한가? (중복 없음)
- [ ] `itemType`이 `ActionCommand`로 설정되었는가?
- [ ] `actionCommandData`가 올바른 ActionCommandData를 참조하는가?
- [ ] `maxStack`이 1로 설정되었는가?
- [ ] ItemDatabase에 등록되었는가?
- [ ] 아이콘이 할당되었는가? (선택)

## 4. 예시: "기본 베기" 검술 아이템

### 4.1 ActionCommandData 설정
```
파일: Assets/Resources/Data/ActionData/BasicSlash.asset

commandName: "기본 베기"
animationName: "slash_basic"
perfectTimings: [2개 히트]
damageRatio: 1.0
```

### 4.2 Item 설정
```
파일: Assets/Resources/Data/Items/Actions/BasicSlash_Item.asset

itemKey: "action_basic_slash"
itemName: "기본 베기"
itemType: ActionCommand
actionCommandData: BasicSlash (ActionCommandData)
maxStack: 1
icon: icon_slash_basic (Sprite)
```

### 4.3 ItemDatabase 등록
```
ItemDatabase.items에 BasicSlash_Item 추가
```

## 5. 유파 검술 vs 습득 검술

### 유파 검술
- SwordArtStyleData의 `CommandSet`에 포함된 검술
- 유파 장착 시 자동으로 사용 가능
- **별도 Item 생성 권장**: 습득 검술로도 사용 가능하도록

### 습득 검술
- 인벤토리에 독립적으로 존재
- 유파와 무관하게 장착 가능
- **Item SO 필수**: 이 가이드대로 생성

**권장 방식**: 모든 검술을 Item으로 만들어두면 유연하게 활용 가능

## 6. 유파 아이템에 검술 연결

유파(SwordArtStyle) 아이템은 검술 아이템과 별개입니다.

### 6.1 SwordArtStyleData 설정
```
파일: Assets/Resources/Data/Styles/ImperialStyle.asset

styleName: "제국군 정규 검술"
commandSet: [검술 ActionCommandData 리스트]
  └─ BasicSlash
  └─ HeavyStrike
  └─ QuickThrust
```

### 6.2 유파 Item 설정
```
파일: Assets/Resources/Data/Items/Styles/ImperialStyle_Item.asset

itemKey: "style_imperial"
itemName: "제국군 정규 검술"
itemType: SwordArtStyle
swordArtStyleData: ImperialStyle (SwordArtStyleData)
  └─ 6.1에서 설정한 SwordArtStyleData 할당
```

## 7. 테스트 방법

### 7.1 에디터에서 테스트
1. CharacterData의 `initialItems`에 검술 아이템 추가
2. Play 모드 진입
3. 인벤토리 UI에서 검술 확인
4. 검술 슬롯에 장착 시도

### 7.2 런타임 테스트
```csharp
// 검술 아이템 추가 테스트
var inventory = CharacterManager.Instance.PlayerCharacter.Inventory;
inventory.AddItem("action_basic_slash", 1);

// 장착 테스트
inventory.EquipItem("action_basic_slash", EquipmentSlotType.ActionSlot1);

// 장착 확인
var equippedActions = inventory.GetEquippedActions();
Debug.Log($"장착된 검술: {equippedActions.Count}개");
```

## 8. 주의사항

### itemKey 명명 규칙
- 검술: `action_*` (예: `action_basic_slash`)
- 유파: `style_*` (예: `style_imperial`)
- 무기: `weapon_*`
- 방어구: `armor_*`

### 중복 방지
- ItemDatabase에서 `itemKey` 중복 확인
- 동일한 검술에 대해 Item을 여러 개 만들지 않기

### 참조 관리
- ActionCommandData 삭제 시 해당 Item의 참조가 깨짐
- 검술 삭제 전 Item 참조 확인 필요

## 9. 자주 하는 실수

### ❌ 잘못된 예시
```
itemType: Weapon (X) → ActionCommand로 설정해야 함
maxStack: 99 (X) → 1로 설정해야 함
actionCommandData: null (X) → 반드시 할당해야 함
itemKey: "Basic Slash" (X) → 공백 없이, 소문자_언더스코어 권장
```

### ✅ 올바른 예시
```
itemType: ActionCommand
maxStack: 1
actionCommandData: BasicSlash (할당됨)
itemKey: "action_basic_slash"
```

## 10. 문제 해결

### 문제: 검술이 인벤토리에 표시되지 않음
- ItemDatabase에 등록되었는지 확인
- `itemKey`가 정확한지 확인
- ItemDatabase가 올바르게 로드되었는지 확인

### 문제: 검술 슬롯에 장착되지 않음
- `itemType`이 `ActionCommand`인지 확인
- 슬롯이 비어있는지 확인
- `EquipmentSlot.CanEquipItem()` 로직 확인

### 문제: 전투에서 검술이 작동하지 않음
- `actionCommandData`가 null이 아닌지 확인
- ActionCommandData의 설정이 올바른지 확인
- `Character.AvailableCommands`에 포함되는지 확인
