# 메인 메뉴 시스템 통합 구현 계획서

**작성일**: 2025년 10월 31일  
**목표**: 인벤토리와 검술 장착 화면을 통합하는 메인 메뉴 시스템 개발 및 UX 개선

---

## 📋 현재 상태 분석

### 기존 구조
1. **MainMenuManager**: 기본적인 Canvas 활성화만 담당
2. **InventoryUI**: 독립적인 패널 형태 (panel GameObject로 show/hide)
3. **ActionCommandEquipUI**: 독립적인 패널 형태 (panel GameObject로 show/hide)
4. **공통점**: 
   - 둘 다 panel.SetActive()로 표시/숨김 제어
   - Character 연결, 상세 패널, 슬롯 시스템 등 유사한 구조

### **Phase 2: UX 개선 기능** ⭐ (우선)

#### 2-1. 포커싱 유지 기능

**목표**: 장착/해제 시 포커스가 자연스럽게 이동

**InventoryUI:**
- [ ] 아이템 그리드에서 장착 시 → 해당 장비 슬롯으로 포커스
- [ ] 장비 슬롯에서 해제 시 → 아이템 그리드의 해당 아이템으로 포커스
- [ ] ScrollRect 자동 스크롤 (기존 로직 활용)

**ActionCommandEquipUI:**
- [ ] 검술 그리드에서 장착 시 → 장착 슬롯으로 포커스
- [ ] 장착 슬롯에서 해제 시 → 검술 그리드의 해당 검술로 포커스
- [ ] ScrollRect 자동 스크롤

**구현 방법:**
- `OnEquipAction()` / `OnUnequipAction()` 완료 후 포커스 타겟 설정
- 기존 ScrollToItemIfOutOfViewDelayed 로직 참고

**예상 시간**: 1~1.5시간

---

#### 2-2. 장착 슬롯에서 시작하는 장비 선택 기능

**목표**: 장착 슬롯 클릭 시 해당 슬롯에 장착 가능한 아이템만 활성화

**InventoryUI:**
- [ ] 장비 슬롯 클릭 시:
  1. [ ] 현재 슬롯 타입 확인 (Weapon/Armor/Accessory/SwordArtStyle)
  2. [ ] 아이템 그리드에서 해당 타입만 활성화
  3. [ ] 나머지 아이템은 비활성화/회색 처리
- [ ] 슬롯 선택 해제 시 (ESC 또는 다시 클릭) → 모든 아이템 원복
- [ ] 시각적 피드백 (슬롯 선택 상태 표시)

**ActionCommandEquipUI:**
- [ ] 장착 슬롯 클릭 시 검술 그리드 전체 활성화 (모두 장착 가능)
- [ ] 슬롯 선택 상태 시각적 표시

**구현 방법:**
- `EquipmentSlotUI.OnSlotClicked` 핸들러 확장
- `ItemSlotUI`에 `SetInteractable(bool)` 메서드 추가
- 슬롯 선택 모드 상태 관리

**예상 시간**: 1.5~2시간

**참고**: 정렬 기능은 보류 (우선순위 낮음)

## 🔧 기술적 고려사항

### 1. Canvas 구조 변경
- **기존**: 각 UI가 독립 Canvas
- **변경**: 하나의 MainMenuCanvas에 통합
- **영향**: Inspector 참조 재설정 필요 (사용자 확인 및 복원)

### 2. 드래그 앤 드롭 구현
- Unity EventSystem의 IPointerHandler 인터페이스 사용
- Canvas에 GraphicRaycaster 필요
- EventSystem GameObject 확인 필요

### 3. 포커싱 시스템
- Unity UI Navigation 시스템 사용 가능
- 또는 커스텀 포커스 관리자 구현
- ScrollRect 자동 스크롤 (기존 InventoryUI 로직 재활용)

### 4. 입력 시스템
- InputSystem에 탭 전환 키 추가 (Tab 또는 Q/E)
- MainMenuManager가 입력 이벤트 구독
- GameInputManager와 통합

## 🎨 UI 설계 가이드

### Top Navigation Bar 디자인
```
┌─────────────────────────────────────┐
│  [소지품]    [검술]                  │ ← TopNavigationBar
├─────────────────────────────────────┤
│                                     │
│         (패널 내용 영역)             │
│                                     │
└─────────────────────────────────────┘
```

**버튼 상태:**
- 선택됨: `interactable = false`, 강조 색상
- 선택 안됨: `interactable = true`, 기본 색상

### 슬롯 선택 모드 시각적 피드백
- **활성화된 아이템**: 정상 색상 (alpha = 1.0)
- **비활성화된 아이템**: 회색 처리 (alpha = 0.5)
- **선택된 슬롯**: 테두리 강조 (Border Image)

### 드래그 앤 드롭 시각적 피드백
- **드래그 중인 아이템**: 반투명 이미지가 마우스 따라다님 (alpha = 0.7)
- **드롭 가능한 슬롯**: 테두리 하이라이트 (녹색 또는 밝은 색)
- **드롭 불가능한 슬롯**: 변화 없음 또는 회색 처리

## 🐛 예상 이슈 및 대응

### 1. Inspector 참조 손실
**원인**: Canvas 구조 변경 시 SerializeField 참조 끊김  
**대응**: 작업 전 백업, 참조 재연결 가이드 제공

### 2. 포커스 이동 버그
**원인**: 슬롯이 동적 생성/삭제되어 참조가 없을 수 있음  
**대응**: null 체크, 안전한 포커스 설정 로직

### 3. 드래그 앤 드롭 레이캐스트 충돌
**원인**: 여러 UI 요소가 겹쳐있을 때 이벤트 처리 순서 문제  
**대응**: Canvas Sort Order 조정, Raycast Target 설정 최적화

### 4. 입력 시스템 충돌
**원인**: 여러 UI가 동시에 같은 키를 사용  
**대응**: 입력 우선순위 설정, 활성화된 패널만 입력 받도록 제어
