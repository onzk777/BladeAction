# 아이템 시스템 명세서

## 1. 시스템 개요

아이템 시스템은 게임 내에서 플레이어가 획득하고 관리할 수 있는 모든 아이템을 처리하는 핵심 시스템입니다. 장비, 소모품, 검술 유파 등 다양한 타입의 아이템을 통합적으로 관리하며, 인벤토리 UI와 장비 시스템을 지원합니다.

### 1.1 핵심 특징
- **하이브리드 데이터 관리**: Unity Asset과 Excel 데이터의 분리 관리
- **에디터 중심 타입 관리**: WeaponType, ArmorType을 ScriptableObject로 관리
- **대용량 데이터 지원**: Excel 기반 대량 아이템 데이터 관리
- **itemKey 중심 참조**: itemKey를 통한 효율적인 아이템 참조 시스템
- **일괄 편집 지원**: 여러 아이템의 공통 속성 일괄 수정

## 2. 하이브리드 데이터 관리 시스템

### 2.1 데이터 분리 구조
- **Unity Asset (Inspector 관리)**: ScriptableObject 참조, 2D Sprite, 사운드 등
- **Excel 데이터 (엑셀 관리)**: 텍스트 데이터, 수치 데이터, 설정값 등
- **itemKey**: Excel에서 관리하되 Unity에서도 자주 확인/참조

### 2.2 기본 아이템 데이터 구조
```csharp
[System.Serializable]
public class ItemData
{
    [Header("Unity Asset References (Inspector에서 설정)")]
    public Sprite icon;                    // 아이콘 (2D Sprite 참조)
    public Sprite appearance;              // 외형 (전투 중 표시)
    public WeaponTypeData weaponType;      // 무기 타입 (ScriptableObject)
    public ArmorTypeData armorType;        // 방어구 타입 (ScriptableObject)
    public StatTable statTable;            // 스탯 테이블 (ScriptableObject)
    
    [Header("Excel Data (Read-only, Excel에서 관리)")]
    [ReadOnly] public string itemKey;      // 아이템 고유 키 (Excel에서 관리)
    [ReadOnly] public string name;         // 이름
    [ReadOnly] public string description;  // 설명
    [ReadOnly] public ItemType type;       // 타입
    [ReadOnly] public int level;           // 필요 레벨
    [ReadOnly] public float baseValue;     // 기본 수치
    [ReadOnly] public int maxStack;        // 최대 중첩 수
}

public enum ItemType
{
    Weapon = 1,        // 무기
    Armor = 2,         // 방어구
    Accessory = 3,     // 보조장비
    SwordplayStyle = 4 // 검술 유파
}
```

{

{

    }

### 6.1 itemKey 표시 및 참조
```csharp
[CustomEditor(typeof(ItemData))]
public class ItemDataEditor : Editor
{
    public override void OnInspectorGUI()
    {
        ItemData itemData = (ItemData)target;
        
        // itemKey를 상단에 강조 표시
        EditorGUILayout.Space();
        EditorGUILayout.BeginVertical("box");
        EditorGUILayout.LabelField("Item Key", EditorStyles.boldLabel);
        EditorGUILayout.TextField("", itemData.itemKey, EditorStyles.textField);
        EditorGUILayout.EndVertical();
        
        // Excel 데이터 섹션 (Read-only)
        EditorGUILayout.LabelField("Excel Data", EditorStyles.boldLabel);
        EditorGUILayout.TextField("Item Name", itemData.name);
        EditorGUILayout.TextField("Description", itemData.description);
        
        // Unity Asset 섹션 (편집 가능)
        EditorGUILayout.LabelField("Unity Assets", EditorStyles.boldLabel);
        itemData.icon = (Sprite)EditorGUILayout.ObjectField("Icon", itemData.icon, typeof(Sprite), false);
        itemData.weaponType = (WeaponTypeData)EditorGUILayout.ObjectField("Weapon Type", itemData.weaponType, typeof(WeaponTypeData), false);
    }
}
```

### 7.1 CombatantInventory 구조
```csharp
[System.Serializable]
public class CombatantInventory
{
    [Header("보유 아이템")]
    public List<OwnedItem> ownedItems = new List<OwnedItem>();
    
    [Header("장비 슬롯")]
    public List<EquipmentSlot> equipmentSlots = new List<EquipmentSlot>();
    
    [Header("설정")]
    public int maxStorageCapacity = 5000;
    
    // 아이템 추가/제거 메서드
    public bool AddItem(ItemData item, int quantity = 1);
    public bool RemoveItem(ItemData item, int quantity = 1);
    public bool EquipItem(ItemData item, int slotIndex);
    public bool UnequipItem(int slotIndex);
}

[System.Serializable]
public class OwnedItem
{
    public ItemData itemData;         // 아이템 데이터 참조
    public int quantity;              // 수량
    public System.DateTime acquiredTime; // 획득 시점
    public bool isEquipped;           // 장착 여부
    
    public OwnedItem(ItemData item, int qty)
    {
        itemData = item;
        quantity = qty;
        acquiredTime = System.DateTime.Now;
        isEquipped = false;
    }
}

[System.Serializable]
public class EquipmentSlot
{
    public string slotName;           // 슬롯 이름
    public ItemType allowedType;      // 허용되는 아이템 타입
    public int slotIndex;             // 슬롯 인덱스
    public bool isEmpty => equippedItem == null;
    public ItemData equippedItem;     // 장착된 아이템
}
```
