# 아이템 시스템 명세서

## 1. 시스템 개요

아이템 시스템은 게임 내에서 플레이어가 획득하고 관리할 수 있는 모든 아이템을 처리하는 핵심 시스템입니다. 장비, 소모품, 검술 유파 등 다양한 타입의 아이템을 통합적으로 관리하며, 인벤토리 UI와 장비 시스템을 지원합니다.

### 1.1 핵심 특징
- **하이브리드 데이터 관리**: Unity Asset과 Excel 데이터의 분리 관리
- **에디터 중심 타입 관리**: WeaponType, ArmorType을 ScriptableObject로 관리
- **대용량 데이터 지원**: Excel 기반 대량 아이템 데이터 관리
- **itemKey 중심 참조**: itemKey를 통한 효율적인 아이템 참조 시스템
- **일괄 편집 지원**: 여러 아이템의 공통 속성 일괄 수정

## 2. 하이브리드 데이터 관리 시스템

### 2.1 데이터 분리 구조
- **Unity Asset (Inspector 관리)**: ScriptableObject 참조, 2D Sprite, 사운드 등
- **Excel 데이터 (엑셀 관리)**: 텍스트 데이터, 수치 데이터, 설정값 등
- **itemKey**: Excel에서 관리하되 Unity에서도 자주 확인/참조

### 2.2 기본 아이템 데이터 구조

#### 아이템 정보 구성
- **기본 정보**: itemKey, itemName, description, itemType, requiredLevel, maxStack
- **Unity Asset 참조**: icon (아이콘), appearance (전투 외형)
- **타입 참조**: weaponTypeKey, armorTypeKey, accessoryTypeKey (키 기반 참조)
- **검술 유파**: SwordArtStyleData (직접 참조)
- **스탯 정보**: statTableKey (재사용 가능한 스탯 테이블 참조)

#### 아이템 타입 분류
- **Weapon**: 무기 (검, 도끼, 활 등)
- **Armor**: 방어구 (갑옷, 투구, 신발 등)
- **Accessory**: 보조장비 (반지, 목걸이, 팔찌 등)
- **SwordArtStyle**: 검술 유파 (특수 아이템)

#### 데이터 참조 방식
- **키 기반 참조**: 타입 데이터는 itemKey로 참조하여 유연성 확보
- **직접 참조**: 검술 유파는 ScriptableObject 직접 참조
- **재사용 구조**: 스탯은 별도 테이블에서 관리하여 중복 제거

## 3. ScriptableObject 기반 타입 관리 시스템

### 3.1 WeaponTypeData (무기 타입)
```csharp
[CreateAssetMenu(fileName = "WeaponType", menuName = "Item/Weapon Type")]
public class WeaponTypeData : ScriptableObject
{
    [Header("기본 정보")]
    public string typeName;           // 표시될 이름
    public string typeKey;            // 내부 식별자
    public Sprite typeIcon;           // 타입 아이콘
    public string description;        // 타입 설명
    
    [Header("무기 특성")]
    public WeaponCategory category;   // 무기 카테고리
    public float baseAttackSpeed;     // 기본 공격 속도
    public float baseRange;           // 기본 사거리
    public int requiredLevel;         // 필요 레벨
}

public enum WeaponCategory
{
    Melee,      // 근접 무기
    Ranged,     // 원거리 무기
    Magic       // 마법 무기
}
```

## 4. 장비 스탯 시스템

### 4.1 장비 스탯 구조체

```csharp
    public float blockPoiseConsumption;   // 막기 Poise 소모량

    public float parryEfficiency;         // 쳐내기 효율 (%)
    public float parryPoiseConsumption;   // 쳐내기 Poise 소모량
    public float parryPoiseAttackPower;   // 쳐내기 Poise 공격력

    public float maxHP;                   // HP
    public float damageReduction;         // DR (피해 감소)
    public float poise;                   // Poise
}
```

### 4.2 StatTable 및 StatDatabase
```csharp
[System.Serializable]
public class StatTable
{
    public string tableKey;           // 테이블 키
    public EquipmentStats stats;      // 장비 스탯
    public string description;        // 스탯 설명
}

[CreateAssetMenu(fileName = "StatDatabase", menuName = "Item/Stat Database")]
public class StatDatabase : ScriptableObject
{
    public List<StatTable> statTables = new List<StatTable>();
    
    public StatTable GetStatTable(string key)
    {
        return statTables.Find(table => table.tableKey == key);
    }
}
```

## 6. itemKey 관리 시스템

### 6.1 itemKey 표시 및 참조
```csharp
[CustomEditor(typeof(ItemData))]
public class ItemDataEditor : Editor
{
    public override void OnInspectorGUI()
    {
        ItemData itemData = (ItemData)target;
        
        // itemKey를 상단에 강조 표시
        EditorGUILayout.Space();
        EditorGUILayout.BeginVertical("box");
        EditorGUILayout.LabelField("Item Key", EditorStyles.boldLabel);
        EditorGUILayout.TextField("", itemData.itemKey, EditorStyles.textField);
        EditorGUILayout.EndVertical();
        
        // Excel 데이터 섹션 (Read-only)
        EditorGUILayout.LabelField("Excel Data", EditorStyles.boldLabel);
        EditorGUILayout.TextField("Item Name", itemData.name);
        EditorGUILayout.TextField("Description", itemData.description);
        
        // Unity Asset 섹션 (편집 가능)
        EditorGUILayout.LabelField("Unity Assets", EditorStyles.boldLabel);
        itemData.icon = (Sprite)EditorGUILayout.ObjectField("Icon", itemData.icon, typeof(Sprite), false);
        itemData.weaponType = (WeaponTypeData)EditorGUILayout.ObjectField("Weapon Type", itemData.weaponType, typeof(WeaponTypeData), false);
    }
}
```

## 7. 인벤토리 시스템

### 7.1 CombatantInventory 구조

#### 인벤토리 구성 요소
- **아이템 저장소**: 최대 5000개 슬롯의 아이템 보관 공간
- **장비 슬롯**: 8개 슬롯 (무기 1개, 방어구 1개, 장신구 5개, 검술 유파 1개)
- **상태 관리**: 잠금 상태, 용량 관리, 이름 설정

#### 아이템 관리 기능
- **추가/제거**: itemKey 기반으로 아이템 수량 관리
- **검색**: 타입별, 조건별 아이템 검색
- **수량 관리**: 스택 가능한 아이템의 수량 처리
- **유틸리티**: 인벤토리 정리, 전체 비우기

#### 장비 시스템
- **장착/해제**: 타입별 슬롯에 아이템 장착
- **호환성 검사**: 아이템 타입과 슬롯 타입 매칭
- **자동 교체**: 기존 장착 아이템을 인벤토리로 이동

### 7.2 OwnedItem (소유 아이템)

#### 소유 정보
- **아이템 참조**: itemKey로 아이템 데이터 참조
- **수량 관리**: 현재 수량과 최대 수량 제한
- **상태 정보**: 장착 여부, 잠금 상태, 획득 시간

#### 수량 처리
- **스택 시스템**: 동일 아이템의 수량 합산
- **수량 제한**: 아이템별 최대 보유 수량 적용
- **유효성 검사**: 아이템 존재 여부 및 수량 유효성

### 7.3 EquipmentSlot (장비 슬롯)

#### 슬롯 구성
- **슬롯 타입**: 무기, 방어구, 보조장비, 검술 유파
- **슬롯 정보**: 이름, 활성화 상태, 인덱스
- **장착 아이템**: itemKey와 수량으로 장착 아이템 관리

#### 장비 슬롯 배치
- **무기 슬롯**: 1개 (주무기)
- **방어구 슬롯**: 1개 (갑옷)
- **장신구 슬롯**: 5개 (반지, 목걸이, 팔찌 등)
- **검술 유파 슬롯**: 1개 (특수 장비)

### 7.4 데이터베이스 구조

#### ItemDatabase (아이템 데이터베이스)
- **역할**: 모든 아이템 데이터의 중앙 관리
- **구성**: 타입 데이터베이스 참조, 스탯 데이터베이스 참조, 아이템 목록
- **특징**: 단일 ScriptableObject에서 모든 아이템 편집 가능
- **검색 기능**: itemKey, 타입별, 키별 검색 지원

#### ItemTypeDatabase (타입 데이터베이스)
- **역할**: 아이템 타입 정의 데이터 관리
- **구성**: 무기 타입, 방어구 타입, 보조장비 타입, 검술 유파
- **특징**: 게임 룰을 정의하는 정적 데이터
- **사용**: 아이템 생성 시 타입 정보 제공

#### StatDatabase (스탯 데이터베이스)
- **역할**: 재사용 가능한 스탯 테이블 관리
- **구성**: 다양한 스탯 조합의 프리셋
- **특징**: 아이템별로 스탯 테이블을 참조하여 중복 제거
- **사용**: 아이템의 스탯 정보 제공

## 8. CSV Import/Export 시스템

### 8.1 시스템 개요
- **목적**: Excel/CSV 파일과 Unity Asset 간의 데이터 동기화
- **특징**: CSV를 단일 소스로 사용하여 데이터 일관성 보장
- **지원 데이터**: StatTable, Item 데이터

### 8.2 StatTable CSV 처리
- **CSV 구조**: tableKey, description, 각종 스탯 수치
- **처리 과정**: CSV 읽기 → 데이터 검증 → Unity Asset 변환
- **에디터 도구**: Database Import/Export 윈도우

### 8.3 Item CSV 처리
- **CSV 구조**: itemKey, 기본 정보, 타입 키, 스탯 키, 검술 유파 키
- **처리 과정**: CSV 읽기 → 타입 매칭 → 아이템 생성/업데이트
- **에디터 도구**: Item Import Export 윈도우

### 8.4 Import/Export 워크플로우
- **Export**: Unity Asset → CSV 파일 생성 (Unity 전용 필드는 제외)
- **Import (Merge)**: CSV 필드만 갱신, Unity Asset 참조(icon, appearance) 보존
  - 빈 값은 미변경 처리
  - 신규 키는 추가, 기존 키는 갱신
  - Unity 전용 필드(icon, appearance, SO 참조 등) 유지
- **검증**: 데이터 무결성 및 참조 유효성 확인

## 9. 범용 드롭다운 모듈

### 9.1 시스템 개요
- **목적**: Inspector에서 데이터베이스 키를 드롭다운으로 선택
- **특징**: 재사용 가능한 범용 모듈로 다양한 시스템에 적용
- **구성**: Attribute + PropertyDrawer 조합

### 9.2 DatabaseKeyAttribute
- **역할**: 드롭다운 설정 정보 정의
- **설정**: 데이터베이스 타입, 리스트 필드명, 키 필드명, 표시명 필드
- **옵션**: 데이터베이스 경로 지정 가능

### 9.3 DatabaseKeyDrawer
- **역할**: Inspector에서 드롭다운 UI 렌더링
- **기능**: 자동 새로고침, 데이터베이스 검색, 키 추출
- **검색 우선순위**: 지정 경로 → Resources 폴더 → AssetDatabase

### 9.4 사용 방식
- **무기 타입**: ItemTypeDatabase의 weaponTypes에서 typeKey 선택
- **스탯 테이블**: StatDatabase의 statTables에서 tableKey 선택
- **자동 완성**: Inspector에서 드롭다운으로 키 선택 가능

## 11. 이벤트 시스템

### 11.1 시스템 개요
- **목적**: 인벤토리 상태 변경을 다른 시스템에 알림
- **패턴**: 싱글톤 + UnityEvent 기반 이벤트 통신
- **특징**: 느슨한 결합으로 UI와 로직 분리

### 11.2 이벤트 타입
- **ItemAdded**: 아이템 추가 시 발생
- **ItemRemoved**: 아이템 제거 시 발생
- **ItemEquipped**: 아이템 장착 시 발생
- **ItemUnequipped**: 아이템 해제 시 발생
- **ItemQuantityChanged**: 수량 변경 시 발생
- **InventoryFull**: 인벤토리 가득참 시 발생
- **InventoryCleared**: 인벤토리 비움 시 발생

### 11.3 이벤트 데이터
- **기본 정보**: itemKey, quantity, itemType
- **장비 정보**: slotType (장비 슬롯 타입)
- **인벤토리 정보**: inventoryName (인벤토리 이름)

### 11.4 이벤트 발생
- **자동 발생**: CombatantInventory의 메서드 호출 시 자동 발생
- **수동 발생**: 직접 이벤트 메서드 호출 가능
- **디버그 지원**: 이벤트 로그 출력 옵션
