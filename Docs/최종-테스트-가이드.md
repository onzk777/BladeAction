# 최종 테스트 가이드

## 🎯 테스트 준비사항

### 1. 필수 오브젝트 생성
1. **CharacterManager 오브젝트**
   - 빈 GameObject 생성 → "CharacterManager"로 이름 변경
   - `CharacterManager` 스크립트 컴포넌트 추가

2. **CombatStatusDisplay UI 설정**
   - 기존 `CombatStatusDisplay` 오브젝트에 `StatusUILayout` 컴포넌트 추가
   - Player용, Enemy용 각각 UI 생성 및 연결

### 2. 스크립트 실행 순서 설정 (권장)
- `Edit` → `Project Settings` → `Script Execution Order`
- `CharacterManager` → Order: 0
- `CombatManager` → Order: 10

## 🧪 테스트 단계

### 1단계: 기본 초기화 테스트
1. **Play 모드 진입**
2. **Console 로그 확인**:
   ```
   [CharacterManager] CharacterData 및 Combatant 초기화 완료.
   [CombatManager] Controller 연결 완료
   [PlayerController] SetupSkeletonMecanim 시작
   [EnemyController] SetupSkeletonMecanim 시작
   ```

### 2단계: 스테이터스 UI 테스트
1. **CombatStatusDisplay 우클릭** → ContextMenu 테스트:
   - "Test Player Take Damage" → HP 감소 확인
   - "Test Player Lose Poise" → Poise 감소 확인
   - "Force Update Status" → UI 업데이트 확인

### 3단계: 전투 시스템 테스트
1. **전투 시작 확인**
   - 턴 표시가 정상적으로 나타나는지 확인
   - 플레이어/적 액션 커맨드가 표시되는지 확인

2. **애니메이션 테스트**
   - 공격 애니메이션이 정상 재생되는지 확인
   - 피격/방어 애니메이션이 정상 재생되는지 확인

### 4단계: Poise 시스템 테스트
1. **패리 성공 시**
   - 공격자의 Poise가 감소하는지 확인
   - Poise가 0이 되면 중단 애니메이션이 재생되는지 확인

## 🔧 문제 해결

### CharacterManager를 찾을 수 없는 경우
- CharacterManager 오브젝트가 씬에 있는지 확인
- CharacterManager 스크립트가 컴포넌트로 추가되어 있는지 확인

### UI가 업데이트되지 않는 경우
- CombatStatusDisplay의 스테이터스 UI 필드들이 연결되어 있는지 확인
- StatusUILayout의 "Connect to CombatStatusDisplay" 사용

### 애니메이션이 재생되지 않는 경우
- PlayerController/EnemyController의 CombatAnimationObject가 연결되어 있는지 확인
- SkeletonMecanim 컴포넌트가 CombatAnimation 오브젝트에 있는지 확인
- SwordArtStyleData의 SpineAnimationAsset이 설정되어 있는지 확인

## ✅ 성공 기준

1. **초기화**: 모든 시스템이 오류 없이 초기화됨
2. **UI**: 스테이터스가 실시간으로 업데이트됨
3. **전투**: 턴 시스템이 정상 작동함
4. **애니메이션**: Spine 애니메이션이 정상 재생됨
5. **Poise**: 패리 시 Poise 감소 및 중단 시스템 작동
