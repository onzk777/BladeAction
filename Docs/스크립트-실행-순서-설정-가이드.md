# 스크립트 실행 순서 설정 가이드

## 설정 방법

1. **Unity 에디터에서 설정**
   - `Edit` → `Project Settings` → `Script Execution Order`
   - 또는 `Edit` → `Preferences` → `Script Execution Order`

2. **권장 실행 순서**
   ```
   CharacterManager (0)
   ├── CharacterData (자동)
   ├── PlayerCombatant (자동)
   └── EnemyCombatant (자동)
   
   CombatManager (10)
   ├── PlayerController (자동)
   ├── EnemyController (자동)
   └── CombatStatusDisplay (자동)
   ```

## 설정 단계

### 1단계: CharacterManager 우선 실행
- `CharacterManager` 스크립트를 찾아서 **Order** 값을 `0`으로 설정
- 이렇게 하면 CharacterManager가 가장 먼저 초기화됩니다

### 2단계: CombatManager 다음 실행
- `CombatManager` 스크립트를 찾아서 **Order** 값을 `10`으로 설정
- CharacterManager 초기화 후에 실행됩니다

### 3단계: 나머지는 자동
- PlayerController, EnemyController, CombatStatusDisplay는 자동으로 적절한 순서로 실행됩니다

## 왜 필요한가?

- **CharacterManager**가 먼저 초기화되어야 PlayerController/EnemyController가 Combatant에 접근할 수 있습니다
- **CombatManager**가 CharacterManager 초기화 후에 실행되어야 Controller 연결이 제대로 됩니다

## 대안 방법

스크립트 실행 순서를 설정하지 않아도 됩니다. 현재 구현된 대기 로직(`WaitForCharacterManagerAndConnect`, `WaitForCharacterManagerAndSetup`)이 자동으로 순서를 맞춰줍니다.

하지만 **성능상 이점**이 있으므로 설정하는 것을 권장합니다.
